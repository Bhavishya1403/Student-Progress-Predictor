How to read these metrics

R² compares squared prediction error with the mean-prediction baseline; 1 is perfect, 0 matches that baseline, and negative values are possible. It is not classification accuracy.

MAE is average absolute error. RMSE is the square root of average squared error and penalizes large mistakes more heavily. Both are in score points.

These model associations do not establish that demographic or preparation features cause score differences. Do not use estimates as an educational decision rule.
